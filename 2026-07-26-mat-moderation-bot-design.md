# Спека: Telegram-бот модерации мата

Дата: 2026-07-26

## Цель

Автоматизировать модерацию мата в чате поддержки (тема — невроз, эмоциональное выговаривание). Бот берёт на себя рутину детекта мата и эскалации наказаний; живой модератор (админ) остаётся для спорных случаев — оскорблений, обесценивания переживаний и т.п., которые бот не различает.

## Стек

- Язык: Python
- Библиотека: `python-telegram-bot`
- База данных: SQLite
- Хостинг: Railway (деплой из GitHub-репозитория)

## Компоненты

1. **Message Handler** — слушает все сообщения в группе, прогоняет каждое через проверку на мат.
2. **Profanity Detector** — нормализует текст (замены букв/цифр на похожие по написанию, удаление разделителей типа `*`/`.`/пробелов между буквами, нижний регистр), затем ищет совпадения со словарём мата.
3. **Violation Tracker** — хранит в SQLite по каждому `user_id`: количество нарушений, дату последнего нарушения, дату окончания бана (если есть).
4. **Punishment Engine** — по текущему счётчику нарушений применяет действие по лестнице.
5. **Admin Commands** — доступны только одному админу (владельцу чата).

## Лестница наказаний за мат

1. **1-е нарушение** — предупреждение в чате: просим удалить мат или заменить на нейтральное слово («блин» и т.п.)
2. **2-е нарушение** — сообщение удаляется ботом
3. **3-е нарушение** — исключение из группы (кик, без постоянного бана)
4. **4-е нарушение** — бан на 30 дней

Уведомления о каждом действии — сообщением в общий чат (публично, все видят).

## Детект замаскированного мата

Вариант: **нормализация текста** (не нечёткое сравнение / Левенштейн — отклонено из-за риска ложных срабатываний, что критично для чата поддержки).

Нормализация перед проверкой:
- цифры → похожие по написанию буквы (0→о, 3→з, 6→б и т.п.)
- удаление разделителей между буквами (пробелы, точки, звёздочки, дефисы внутри слова)
- приведение к нижнему регистру

Затем нормализованный текст сверяется со словарём.

## Счётчик нарушений — сброс

Счётчик нарушений у юзера обнуляется, если человек не нарушал правила **30 дней подряд**. Проверяется фоновой задачей.

## Защита от ложного повторного нарушения

Если сообщение является ответом (reply) на предупреждение бота и **не содержит мата** — считается исправлением, новым нарушением не засчитывается.

## Автоматический разбан

Фоновая задача (раз в день):
- снимает бан с юзеров, у которых `забанен_до` уже в прошлом
- обнуляет счётчик у юзеров, которые не нарушали 30+ дней

## Команды администратора

Доступны только одному админу (владельцу чата):
- `/addword <слово>` — добавить слово в словарь мата
- `/removeword <слово>` — убрать слово из словаря
- `/unban <@юзер>` — досрочный ручной разбан
- `/wordlist` — посмотреть текущий словарь (ответ приходит в личку боту, не в общий чат)

## Команда для участников

- `/mystats` — юзер в личке боту видит: текущее количество нарушений, дату последнего нарушения, через сколько дней счётчик обнулится

## Обработка ошибок

- Если у бота нет прав администратора в группе (не может кикать/банить/удалять сообщения) — при первой попытке выполнить действие бот пишет админу в личку с просьбой выдать права
- Если БД недоступна при старте — бот логирует ошибку и не запускается (лучше не работать вообще, чем работать без памяти о нарушениях пользователей)

## Тестирование (ручное, перед запуском)

- [ ] Обычное матерное слово → 1-е нарушение → предупреждение в чате
- [ ] Матерное слово с заменой букв/цифр → распознаётся так же, как обычное
- [ ] Безобидное слово, похожее по написанию на мат → НЕ засчитывается как нарушение
- [ ] Reply на предупреждение бота без мата → не создаёт новое нарушение
- [ ] 4 нарушения подряд у одного юзера → доходит до бана на 30 дней
- [ ] Автоматический разбан по истечении 30 дней срабатывает без участия админа
- [ ] Счётчик обнуляется после 30 дней чистого поведения
- [ ] `/mystats` показывает корректные данные
- [ ] `/addword` / `/removeword` корректно меняют словарь и сразу применяются к новым сообщениям
- [ ] Бот без прав администратора корректно уведомляет владельца в личку

## Вне рамок текущей версии (на будущее)

- Модерация оскорблений и обесценивания переживаний — контекстно-зависимая задача, словарный бот с этим не справится, требует живого модератора
- Мягкий режим для новых участников (не считать первое нарушение новичка) — обсуждалось, отложено
- Отдельный лог-канал с историей всех действий бота — обсуждалось, отложено
